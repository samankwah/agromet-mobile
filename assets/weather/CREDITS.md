## Licence notes

- **CC BY-SA** requires attribution and that adaptations be shared under the
  same licence. The images are displayed unmodified apart from scaling, so
  attribution is the operative obligation here.
- If any image is replaced, update this file in the same change — the
  credit and the asset must never drift apart.
- These credits are surfaced in-app; see `src/shared/data/weatherBackdrops.ts`,
  which is the single source both the renderer and any credits screen read.
